# Projects

Per-repo notes — context that doesn't belong in that repo's `AGENTS.md` overlay.

## Filename

Match the repo or folder name: `agent-bootstrap.md`, `dotfiles.md`, `new-setup.md`.

## Template

```markdown
# Project: name

**Path:** ~/Dev/...
**Status:** active | paused | archived

## Purpose
One paragraph.

## Agent notes
- Bootstrap: `agentboot` / `./install.sh` commands
- Key conventions or gotchas
- Links to ADRs in `../decisions/`

## Open items
- [ ] ...
```
