# FreePlayground Agent Notes

## What this repo is
This is my proof-of-work lab repo for DevSecOps / Cloud Security learning and homelab experiments.

## Non-negotiables
- Weekly logs use week numbers only (Monday–Sunday). I avoid real calendar dates.
- In repo docs (README, descriptions, weekly logs), I write in first person (me/my/mine) and avoid second person (you/your).
- I merge into main using merge commits (no squash).

## Where to log work
- Weekly logs live under `docs/weekly/weeks/week-XX.md`.
- Weekly evidence images live under `docs/weekly/images/` with week-based naming.

## How I want changes made
- I keep changes small and easy to review.
- I update documentation alongside behavior changes.
- I do not scan the whole repo. I use rg and open only relevant files.

## Definition of done
- I leave a minimal diff plus the exact commands needed to verify the change.
- I note what changed in the relevant weekly log.
